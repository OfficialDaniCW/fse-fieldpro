## Interactive Elements

### Search Behavior
```
User types: "hydraulic"
  ↓
Manuals filtered to those matching:
  - Title contains "hydraulic"
  - Manufacturer contains "hydraulic"
  - Model contains "hydraulic"
  - Summary contains "hydraulic"
  ↓
Results stay grouped by (Brand → Component Type)
```

### Expand/Collapse Behavior
```
Brand [▼] — Click to collapse all sub-categories
  ├─ Category [▼] — Click to collapse manuals
  │  ├─ Manual [>] — Click to open detail view
  │  ├─ Manual [>]
  │  └─ Manual [>]
  ├─ Category [►] — Already collapsed
  └─ Category [▼]
```

### TOC Navigation (Desktop)
```
User clicks section in TOC
  ↓
Page scrolls smoothly to section
  ↓
Section appears in viewport
  ↓
Can continue reading or click another TOC link
```

### Full-Screen PDF
```
User clicks "Full Screen" button
  ↓
Browser enters fullscreen mode
  ↓
PDF fills entire screen
  ↓
Download & Close buttons available in header
  ↓
Click Close or press Escape to exit
```

## Color Scheme

**Primary Brand Color:** #CC0000 (Red)
- Buttons, icons, important highlights
- Consistent with FSE branding

**Section Colors:**
- **Hydraulic:** Blue (`blue-50`, `blue-200`, `blue-900`)
- **Electrical:** Yellow (`yellow-50`, `yellow-200`, `yellow-900`)
- **Mechanical:** Purple (`purple-50`, `purple-200`, `purple-900`)
- **Parts:** Green (`green-50`, `green-200`, `green-900`)
- **Miscellaneous:** Gray (`gray-50`, `gray-200`, `gray-900`)

**Alert/Warning Colors:**
- **Safety Warnings:** Orange (`orange-50`, `orange-300`, `orange-900`)
- **Success:** Green (`green-500`, `green-600`)
- **Info:** Blue (`blue-50`, `blue-200`, `blue-900`)

## Typography

**Headings:**
- Page title: 1.125rem (18px), font-bold, white
- Section heading: 1rem (16px), font-bold, gray-800
- Sub-section: 0.875rem (14px), font-semibold, gray-900
- Category label: 0.875rem (14px), font-semibold

**Body Text:**
- Primary: 0.875rem (14px), gray-700/800
- Secondary: 0.75rem (12px), gray-500/600
- Badges: 0.75rem (12px), font-medium

## Responsive Breakpoints

**Desktop (≥1024px):**
- 2-column layout (TOC sidebar + main content)
- TOC sticky positioning
- Full PDF height: 500px
- Wide spacing

**Tablet (768px-1023px):**
- Single column or narrow sidebar
- TOC toggleable
- PDF height: 400px
- Medium spacing

**Mobile (<768px):**
- Full-width single column
- TOC collapsible above content
- PDF height: 300px
- Tight spacing
- Larger touch targets (h-12 buttons)

## Accessibility Features

- **Keyboard Navigation:** All buttons/links accessible via Tab
- **Focus Indicators:** Visible focus states on buttons
- **Icon Labels:** Aria-labels on icon-only buttons
- **Semantic HTML:** Proper heading hierarchy (h1 → h2 → h3)
- **Color Contrast:** All text meets WCAG AA standards
- **Skip Links:** Not explicitly shown (could be added)

---

## Usage Tips for Designers/Developers

1. **Consistent spacing:** Use Tailwind px/py scale (2, 3, 4, 5 units)
2. **Border radius:** Mostly `rounded-lg` and `rounded-xl`
3. **Shadows:** `shadow-sm` for cards, no shadow for plain backgrounds
4. **Hover states:** `hover:bg-gray-50`, `hover:text-[#CC0000]`
5. **Transitions:** All hover effects use `transition-colors`
6. **Z-index:** PDF fullscreen uses `z-50`, modals use `z-50`
